# 中八解球 Android

原生 Android 项目，目前实现 **自由练习交互原型**和基于 GitHub 仓库的版本检查/下载安装。

界面使用自绘球台，自动适配竖屏和横屏；可以拖动母球/目标球摆球、选择目标球和母球击点、调整 0–90° 角度与力度、击球和重置球型。台面展示母球到目标球的虚线，以及目标球延长线。顶部“更新”会读取仓库的 `update.json`，发现新版本后下载 APK 并交给 Android 系统确认安装。

## 打开项目

用 Android Studio 打开此目录，安装 Android SDK Platform 35 后运行 `app` 配置。当前开发环境没有 Android SDK 或 Gradle，因此尚未生成 APK，也无法在模拟器或真机上验证布局。

## 当前范围

- 击球和线路是二维演示模型，不是经台球物理标定的精确解球计算。
- 击点、角度和力度控件已呈现；本版击球动画/旋转、碰撞、库边反弹和袋口判定还未实现完整物理计算。
- AR 标签是功能占位，会明确提示相机识别模块尚未接入。真实 AR 需要相机取景、球台边框/袋口识别、透视校正、球体识别和现场校准。
- 新版本同步到 GitHub 时，需要一起更新 `update.json` 中的版本号和 APK 下载地址。

后续可逐步替换线路几何和击球模型，并实现相机识别与手动校准流程。
