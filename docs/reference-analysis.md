# Billiards City 3.0.51 参考分析

## 分析对象和证据

- 用户提供的本地 APK：`Billiards City_3.0.51.apk`。
- 包名：`com.billiards.city.pool.nation.club`；版本代码 121；目标 Android API 31。
- APK 包含 Cocos2d 原生库 `lib/arm64-v8a/libBilliards.so`、球台/球体/阴影的 3D 资源和打包资源。
- 原生符号可确认 `AimLine`、`PoolTable::getCueBallNextPostion`、`Game::shoot`、`GameArcade::shoot` 和 `GameArcadeNew::shoot`。这些证明了瞄准、路径预测、出杆和闯关模块的存在；不代表已恢复源码或精确物理参数。

## 在本项目中的实现

保留练习所需的交互概念：球台、球杆瞄准、辅助线、拉杆蓄力、击球动画、碰撞、入袋。按中八解球的横屏练习需求重新实现，加入母球击点、杆角、摆球、十五球球局和重试上一杆。没有接入关卡、地图、星级、奖励或解锁逻辑。

使用项目自己的 Java 视图和物理引擎；没有把参考 APK 的原生库、图片或打包资源放入发布包。原版的页面与手感不能凭静态符号宣称已被完整移植。

## 物理边界

球台有效区域比例 2:1；计算坐标与像素分离，以固定 240 Hz 步长模拟等质量球碰撞、库边恢复系数、恒定摩擦减速和圆形袋口。高/低杆只近似作用于首次碰撞后的母球速度，侧旋只近似作用于库边反弹，杆角只改变平面速度。

这些参数没有经过真实中式球台标定，不模拟跳球和扎杆。辅助线忽略旋转与后续多球碰撞。后续需要根据真实球径、台面尺寸、库边、袋口和实测击球轨迹校准。

## 验证

`tools/test-physics.ps1` 验证正面碰撞、停止、恢复球局、母球摆放不影响目标球、重叠拒绝、中袋入袋、母球重摆保留上一杆、库边反弹、无重叠十五球球局和最大力度开球数值稳定性。

Android 构建与 lint：`tools/build.ps1`。模拟器交互验证记录见 `docs/qa.md`。
